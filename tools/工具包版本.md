# 工具包版本信息

>
> ⚠️ 真源永远是 zip 包本身，本表只是给人看的标注，替换包后必须同步更新。

|---|---|---|
| `dcc.zip` | dcc + 内置 androguard / apktool 3.0.3 | dex2c 工具集；**勿升级勿替换**（冻结，历史：报错三/九/四/五） |
| `dex2c.zip` | **v1.0.0**（tag `v1.0.0`，`1bf55f3`；包内 `VERSION` 自报 v1.0.0） | 第二转译引擎（`--dex2c`，2026-10-14 接入）。**源码在父目录 `../Dex2C/`（自研 fork）**，分发包 = 该仓库 Release 资产 `Dex2C-<tag>.zip` 原样（顶层 `Dex2C/`），下载改名 `tools/dex2c.zip` 即可。与 dcc（冻结）并行、输出契约等价：`--no-build --project-archive` 产工程包（`jni/nc/*.cpp` + `compiled_methods.txt`），STEP3+ 下游零感知；CLI 差异（`-i`/`-o` 旗标式，`-o` 在 no-build 下传哑值）由 protect.sh 调用处吸收。v1.0.0 = Termux/Linux/Windows 跨平台路径 + 构造函数抽取闪退修复（根因见 `../Dex2C/docs/d2c对比与构造函数闪退分析.md`）。**换版后必须删 `tools/Dex2C/` 解压产物**（`ensure_dex2c` 幂等靠"dcc.py 存在"判断，旧产物在会静默用旧版）。 |
