# 工具包版本信息

> `tools/` 下所有分发包的版本登记表。**换版本 = 直接替换对应 zip + 改本表一行**，调用处零改动（分发文件名不带版本号）。
>
> ⚠️ 真源永远是 zip 包本身，本表只是给人看的标注，替换包后必须同步更新。

| 工具包 | 版本 | 说明 |
|---|---|---|
| `dcc.zip` | dcc + 内置 androguard / apktool 3.0.3 | dex2c 工具集；**勿升级勿替换**（冻结，历史：报错三/九/四/五） |
| `dpt-shell.zip` | **v1.1.4**（tag `v1.1.4`，`0ff7ccb`；`dpt.jar -v` 自报 1.1.4，与 tag 一致） | 加壳工具（packer 模块 `--packer` 使用，`scripts/packer/packer.sh`）。**源码在父目录 `../dpt-shell/`（自研二改项目），换版时直接查源码核对契约，不必反编译 jar**：CLI 选项看 `dpt/src/main/java/com/luoye/dpt/config/Const.java`、产物命名看 `AndroidPackage.buildPackage`（`-o` 传目录 → `<base>_unsign.apk`）、解压布局看 `getExecutablePath()` 与 `shell/build.gradle`。换版后必须删本地的 `tools/executable/` 解压产物（`ensure_dpt` 幂等靠"jar 存在"判断，旧产物在会静默用旧版）。历史归档见 `tools/dpt版本/`。**v1.1.0 变更**：默认 dex 加载改为磁盘（首次启动落盘 `code_cache/i11111i111.zip`，之后直接读），内存路径降为 opt-in（`--use-inmemory-dex` 才启用）；旧 `--disable-inmemory-dex` 保留为 deprecated no-op。`packer.sh` 不传该参数，故默认磁盘加载自动生效，`packer.sh` 零改动。**v1.1.3 变更**：①壳内后台分级 dexopt（解密落盘 5s 后 quicken 编译，消启动期 1,660 次 VerifyClass，第二次起冷启动受益；详见 `docs/后台dexopt方案.md` + `docs/atrace启动轨迹归因报告.md`）；②载荷 v5 分块压缩；③`-S` 语义收敛为统一 0x0e 填料；④字符串解密桩 L1 缓存；⑤`dpt.jar -v` 修复自报版本。 |
