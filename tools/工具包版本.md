# 工具包版本信息

> `tools/` 下所有分发包的版本登记表。**换版本 = 直接替换对应 zip + 改本表一行**，调用处零改动（分发文件名不带版本号）。
>
> ⚠️ 真源永远是 zip 包本身，本表只是给人看的标注，替换包后必须同步更新。

| 工具包 | 版本 | 说明 |
|---|---|---|
| `dcc.zip` | dcc + 内置 androguard / apktool 3.0.3 | dex2c 工具集；**勿升级勿替换**（冻结，历史：报错三/九/四/五） |
| `dpt-shell.zip` | **v1.1.0**（tag `v1.1.0`，`ec4c18c`；⚠ `dpt.jar -v` 仍自报 `1.0.0`——`build.gradle` 的 `appVersionName` 未随 tag 递增，v1.0.0~v1.1.0 一直如此，勿据此判断版本） | 加壳工具（packer 模块 `--packer` 使用，`scripts/packer/packer.sh`）。**源码在父目录 `../dpt-shell/`（自研二改项目），换版时直接查源码核对契约，不必反编译 jar**：CLI 选项看 `dpt/src/main/java/com/luoye/dpt/config/Const.java`、产物命名看 `AndroidPackage.buildPackage`（`-o` 传目录 → `<base>_unsign.apk`）、解压布局看 `getExecutablePath()` 与 `shell/build.gradle`。换版后必须删本地的 `tools/executable/` 解压产物（`ensure_dpt` 幂等靠"jar 存在"判断，旧产物在会静默用旧版）。历史归档见 `tools/dpt版本/`。**v1.1.0 变更**：默认 dex 加载改为磁盘（首次启动落盘 `code_cache/i11111i111.zip`，之后直接读），内存路径降为 opt-in（`--use-inmemory-dex` 才启用）；旧 `--disable-inmemory-dex` 保留为 deprecated no-op。`packer.sh` 不传该参数，故默认磁盘加载自动生效，`packer.sh` 零改动。 |
